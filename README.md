Renoir is a Rust based distributed data processing platform based on the dataflow paradigm that provides an ergonomic programming interface, similar to that of Apache Flink, but has much better performance characteristics. 

On top of it, we want to implement streaming ML forests, in particular Streaming Random Patches (SRP) and Adaptive Random Forest (ARF).

The goal is to be the best in terms of performance and accuracy wrt others distributed framework, embracing both vertical and horizontal parallelism.
